# Roadmap

Gear Match is a public camera and lens recommendation app. The current focus is
turning the prototype into a maintainable open-source project with reliable
data, tests, and contributor documentation.

## Now

- Keep the repository licensed and easy to run locally.
- Expand tests for recommendation scoring, i18n parity, currency formatting,
  and region-aware store links.
- Continue replacing missing product images with verifiable, license-safe
  sources.
- Improve README and contribution docs for external contributors.

## Next

- Document the recommendation data schema.
- Add issue templates for data corrections, translation fixes, and bug reports.
- Add accessibility checks for the questionnaire and result cards.
- Add a review workflow for product data changes.
- Separate reusable recommendation logic from UI where it reduces maintenance
  cost.

## Later

- Publish a stable data package or documented JSON export if there is external
  demand.
- Add more camera systems, lens mounts, and regional store search providers.
- Add transparent scoring explanations to each result card.
- Build a public changelog for data updates and recommendation changes.

## Non-goals

- Scraping private or copyrighted product databases.
- Adding opaque paid recommendations.
- Collecting user accounts or personal camera profiles without a clear privacy
  model.
