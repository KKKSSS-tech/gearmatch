# Changelog

All notable public changes to Gear Match are tracked here.

## 0.1.0 - 2026-07-09

### Added

- Open-source project metadata in `package.json`.
- MIT license.
- Contributor guide, security policy, code of conduct, roadmap, issue templates,
  pull request template, and Dependabot configuration.
- English README overview for non-Japanese contributors and reviewers.

### Existing App Scope

- React/Vite single-page app for camera and lens recommendations.
- 8 UI locales and 13 region-aware store-search routes.
- Product data split across camera and lens segment modules.
- Recommendation tests for search, currency, store-link, and i18n behavior.
- CI workflow for lint, tests, and production build.

### Verification

- `npm run lint`
- `npm test` - 96 tests passing
- `npm run build`
