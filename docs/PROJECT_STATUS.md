# Project Status

Gear Match is an early public OSS project, not a mature ecosystem dependency.
This page keeps the public status explicit so reviewers and contributors can
understand what exists today and what is still being built.

## Public Links

- Repository: https://github.com/KKKSSS-tech/gearmatch
- Live app: https://gearmatch-steel.vercel.app

## Current Scope

- React/Vite camera and lens recommendation app.
- 8 UI locales.
- 13 region-aware store-search configurations.
- Camera and lens product data split into reviewable segment modules.
- Search and scoring logic with tests.
- CI workflow that runs lint, tests, and production build.
- MIT license and contributor-facing project docs.

## Current Public Metrics

As of 2026-07-09:

- The project is public and open source under the MIT license.
- The repository is new and currently has no meaningful dependent packages,
  dependent repositories, forks, stars, or npm download metrics.
- Public pull-request history is limited; most work so far has been direct
  maintainer commits.

These numbers are intentionally documented without inflation. The project is
being prepared for external contribution rather than presented as an already
large dependency.

## Maintenance Priorities

1. Improve data quality with source-linked camera and lens corrections.
2. Expand tests around recommendation scoring and regional store routing.
3. Improve accessibility for the questionnaire and result cards.
4. Document the data schema and scoring behavior clearly enough for external
   contributors to review changes.
5. Keep image sources license-safe and avoid opaque scraping.

## Good External Contributions

- Correcting camera or lens data with a reliable source.
- Adding product images from clearly licensed sources.
- Fixing translations and i18n parity.
- Adding tests for recommendation edge cases.
- Improving accessibility and keyboard navigation.
- Improving deployment or QA documentation.
