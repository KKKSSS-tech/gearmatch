# Code of Conduct

Gear Match uses a simple contributor standard:

- Be respectful and specific.
- Assume good intent, but accept corrections quickly.
- Keep criticism focused on the code, data, documentation, or user impact.
- Do not harass, threaten, or discriminate against other contributors.
- Do not post private information, credentials, or non-public user data.

Maintainers may edit, hide, or remove comments and issues that make the project
harder to work on in good faith. Repeated abusive behavior may result in being
blocked from the repository.

The goal is a small, practical project where people can improve photography
recommendation data and UI logic without avoidable friction.
